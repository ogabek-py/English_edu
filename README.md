# English Education Project

Ushbu loyiha ingliz tilini o'rgatishga mo'ljallangan.

## Loyiha haqida
Loyiha Django freymvorkida yaratilgan va foydalanuvchilarga ingliz tilini o'rganishda yordam beradi.

## O'rnatish
1. Virtual muhitni yarating:
   ```bash
   python -m venv venv
   ```
2. Virtual muhitni faollashtiring:
   - Windows: `venv\Scripts\activate`
3. Kerakli paketlarni o'rnating:
   ```bash
   pip install -r requirements.txt
   ```
4. Migratsiyalarni amalga oshiring:
   ```bash
   python manage.py migrate
   ```
5. Serverni ishga tushiring:
   ```bash
   python manage.py runserver
   ```
